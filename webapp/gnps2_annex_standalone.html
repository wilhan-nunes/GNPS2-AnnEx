All computation runs client-side via RDKit.js (loaded from a CDN — cheminformatics of this depth has no pure-JS equivalent) and plain JavaScript. GNPS2 requests go directly from your browser to gnps2.org over CORS.
One exception: library rows whose only structure field is INCHI (no SMILES) are resolved via a best-effort, exact-match lookup to PubChem (structure identifier only, never your spectra/task data) before scoring, since no browser-side toolkit here can parse InChI — see the code comment near deriveSmilesFromInchi.
Biological context queries send only the InChIKey first block of each candidate structure to the MASST records API (masst-records.gnps2.org), currently via a CORS proxy because that service does not allow browser requests yet — see MASST_CORS_PROXY.
Known difference from the Python app: on rare positional-isomer group ties (~1% of scans in testing), this port and the Python scorer can pick different, equally-valid tied groups — see the code comment near exactToPositional for details.
