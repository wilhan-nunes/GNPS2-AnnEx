TopKonfidence

Score library annotations with a cleaner starting point.

TopKonfidence reviews GNPS2 library matches scan by scan, groups hits that agree on the same core structure, and turns that evidence into a confidence score you can inspect in detail.

1. Load

Enter a completed GNPS2 task ID from FBMN, Classical Networking, or Library Search.

2. Score

We combine structure agreement, spectral similarity, and library class quality.

3. Inspect

Open any proposed compound to see the detailed evidence and mirror-plot links.

Open a task

Submit a GNPS2 task ID and the dashboard will load the results view directly.

Open dashboard only
Advanced scoring options, including spectral entropy similarity, remain available once the dashboard opens.

What the score means

The scan-level confidence score runs from 0 to 100 and highlights whether a proposed annotation is reliable, less reliable, or unreliable.

  • Structure agreement across library hits carries the most weight.
  • Entropy similarity can be used when spectra are available.
  • Library class quality helps distinguish stronger and weaker reference evidence.
